A one-liner entry for [Angry Judge: The Short Rant Contest](https://make.fun/bounty/u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046): a short, funny rant about a small everyday annoyance, the self-checkout machine accusing an honest shopper of stealing spinach.

## How it works

Run `main.py` and it writes one rant, a single line of plain text, to `/output/entry.txt`.

```sh
python3 main.py
```

The text is under the 400-character gate, so it goes before the judge as-is.
